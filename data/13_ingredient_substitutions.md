# ของทดแทนวัตถุดิบ (Substitutions)
หมวด: ความรู้ทั่วไป
- น้ำปลา → ซีอิ๊วขาว (ใช้ปริมาณ 1:1) หรือเกลือ 1/4 ช้อนชา ต่อน้ำปลา 1 ช้อนโต๊ะ; สำหรับมังสวิรัติใช้ซีอิ๊วขาวหรือซอสถั่วเหลือง
- ซอสหอยนางรม → ซอสเห็ดหอม (สูตรเจ) หรือซีอิ๊วขาวผสมน้ำตาลเล็กน้อย
- น้ำตาลปี๊บ → น้ำตาลทรายแดง หรือน้ำตาลทรายขาว (ใช้น้อยกว่าเล็กน้อย)
- กะทิ → นมสดหรือนมข้นจืด (รสมันน้อยกว่า) หรือนมอัลมอนด์ไม่หวาน
- น้ำมะนาว → น้ำมะขามเปียก หรือน้ำส้มสายชู (ใช้ครึ่งหนึ่งของปริมาณ)
- ใบกะเพรา → โหระพา (กลิ่นต่างแต่ใช้แทนได้)
- ข่า → ขิง (กลิ่นต่างกัน แนะนำใช้น้อยลง)
- ไข่ (ในงานอบ) → กล้วยบด 1/4 ถ้วย หรือเมล็ดแฟลกซ์บด 1 ช้อนโต๊ะ + น้ำ 3 ช้อนโต๊ะ ต่อไข่ 1 ฟอง
- เนย → น้ำมันพืช ใช้ 3/4 ของปริมาณเนย
